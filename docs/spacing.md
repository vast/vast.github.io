# Система отступов

Все вертикальные отступы на сайте выводятся из нескольких токенов в `_sass/core/_tokens.scss`. Никаких «на глаз» `margin: 2rem` — только токены.

## Главный принцип: отступы оптические

Отступ — это просвет, который видит читатель, а не расстояние между CSS-коробками:

- у текста верхний край — **x-height первой строки**, нижний — **базовая линия последней строки**;
- у картинок, блоков кода, рамок и пунктирных линий край — сама рамка или линия.

Коробка строки шире букв: над x-height и под базовой линией остаётся пустое место (у Geist Mono 16px на интерлиньяже 1.65 это 10.4px сверху и 7.5px снизу). Если его не убрать, между двумя абзацами прибавятся оба поля, а между картинкой и абзацем только одно, и пропорции на глаз поедут.

Поэтому текстовые блоки обрезаются по краям букв миксином `trim-to-ink` (`_sass/core/_base.scss`). После этого `margin-top: var(--paragraph-gap)` означает ровно 30px от базовой линии до x-height следующего абзаца.

## Шкала

Значения для основного текста (16px, интерлиньяж 1.65):

| Токен | Значение | Что это | Где |
|---|---|---|---|
| `--leading` | 26.4px | интерлиньяж, `1.65rem` | шаг строк; от базовой до базовой при «следующей строке» |
| `--line-gap` | ≈17.9px | просвет строки: интерлиньяж − 1ex | заголовок → текст, абзац → список, подпись → значение, пунктир → текст в строках списков и таблиц |
| `--list-gap` | ≈6px сверху (≈24px на глаз) | между пунктами списка | пункты не обрезаются, поэтому к отступу прибавляется просвет строки |
| `--paragraph-gap` | 30px | **межабзац** | между абзацами; абзац → врезка; врезка → врезка; внутри рамок; дата → текст |
| `--subsection-gap` | 45px | ¾ межстрочника | перед h3/h4; текст → P. S. |
| `--interline` | 60px | **межстрочник** = 2 межабзаца | после врезки; перед h2; вокруг `<hr>`; шапка → название; между блоками подвала поста |
| `--section-gap` | 120px | 2 межстрочника | между разделами: посты в ленте, реклама курса, рубрики, подвал |

Всё выводится из `--line-height` и `--paragraph-gap`. Чтобы сделать ритм плотнее или свободнее, меняйте `--paragraph-gap`, остальное пересчитается.

`--line-gap` содержит `1ex` и вычисляется в месте использования, то есть от кегля самого элемента. Поэтому дата мелким кеглем после названия встаёт ровно через интерлиньяж: `margin-top: var(--line-gap)` на дате считается от её x-height.

## Правила

### Текст в посте (`.post-contents`)

- **Абзац → абзац:** межабзац.
- **Заголовок → текст, абзац → список:** просвет строки. Текст встаёт на следующую строку, как продолжение.
- **Перед h2:** межстрочник. **Перед h3/h4:** ¾ межстрочника. Бордеров у заголовков нет: раздел отделяется только расстоянием.
- **Пункты списка:** `--list-gap`. Абзацы внутри одного пункта разделены межабзацем.
- **`<hr>`:** межстрочник сверху и снизу.
- **P. S.:** ¾ межстрочника после текста, межстрочник после врезки.

### Врезки

Врезка — всё, что прерывает поток текста: блоки кода, картинки (абзац с одной картинкой), `<figure>`, цитаты, видео (`.youtubeVideo`), `.img--break`, выделенные фразы (`.outstanding`). Список задан в переменной `$inserts` в `_sass/modules/_posts.scss`. Новый тип врезки добавляйте туда же.

- **Текст → врезка:** межабзац.
- **Врезка → что угодно:** межстрочник.
- **Врезка → врезка:** межабзац.

### Рамки и строки между пунктирами

- **Внутри рамки** (блок кода, выделенное правило, плашка курса, карточка на главной): межабзац от рамки до текста или картинки.
- **Строки между пунктирными линиями** (рубрики, переключалка «раньше-позже», архив, таблицы): просвет строки от линии до x-height и от базовой линии до линии.
- **Подпись раздела** (`.section-caption`): просвет строки от пунктира. Первая строка списка под ней встаёт на следующую строку.

### Шапка, лента, подвал

- Верх окна → шапка: межабзац. Шапка → название поста или имя на главной: межстрочник.
- Название → дата: следующая строка (между базовыми ровно интерлиньяж). Дата → текст: межабзац.
- Посты в ленте, карточка → первый пост, последний пост → архив: два межстрочника.
- Подвал поста: P. S. → «Поделиться» — межабзац; → «раньше-позже» — межстрочник; → курс → рубрики — по два межстрочника.
- Рубрики и подвал сайта лежат на тёмной полосе во всю ширину (`full-bleed-band`). От последней строки до линии подвала два межстрочника: межстрочник снизу у полосы и межстрочник сверху у подвала. От © до низа страницы — межстрочник.

## Как это устроено

### `trim-to-ink`

Миксин добавляет элементу `::before` и `::after` с `display: table` и отрицательными отступами, равными полю над x-height и под базовой линией. Поля посчитаны по метрикам Geist Mono (ascent 1.005em, descent .295em, x-height .53em) и `--line-height`:

```scss
@include trim-to-ink;              // текст
@include trim-to-ink($caps: true); // текст капсом: верх по прописным (.71em), а не по x-height
@include trim-to-ink-padding(var(--paragraph-gap)); // когда псевдоэлементы заняты: вычитаем поля из padding
```

Ограничения:

- **Интерлиньяж элемента должен быть `var(--line-height)`.** Иначе поля посчитаются неверно. Заголовки поэтому набраны с тем же интерлиньяжем, что и текст.
- **Псевдоэлементы заняты.** У блоков с плюсиками по углам (`blueprint-box`) используйте `trim-to-ink-padding`.
- **Внутри flex не выравнивайте по `baseline`.** Flex берёт базовую линию у пустого псевдоэлемента. Обрезанные блоки кончаются ровно на базовой линии, поэтому выравнивайте по `flex-end` (см. `.site-header`, `.section-caption`).
- **Flex- и grid-контейнер обрезать нельзя:** псевдоэлементы станут их элементами. Обрезайте детей.
- **Абзацы с одной картинкой не обрезаются:** в них нет строк текста.

### Почему не `text-box`

CSS-свойство `text-box: trim-both ex alphabetic` делает то же самое нативно. Но в Chrome после подгрузки шрифта оно иногда добавляет лишние ~10px перед строкой посреди абзаца, и строки разъезжаются. Пока этот баг не исправлен, используем миксин.

## Как проверять

Проверяйте в браузере, а не в DevTools по коробкам: коробки врут на величину полей строки. Базовую линию и x-height удобно мерить пробой: пустой `inline-block` садится на базовую линию.

```js
function probe(el, atEnd, height) {
  const s = document.createElement('span')
  s.style.cssText = `display:inline-block;width:0;height:${height}`
  atEnd ? el.appendChild(s) : el.prepend(s)
  const y = s.getBoundingClientRect().top
  s.remove()
  return y
}
const baseline = el => probe(el, true, '0')   // базовая линия последней строки
const xHeight = el => probe(el, false, '1ex') // x-height первой строки

xHeight(next) - baseline(prev) // оптический отступ между двумя абзацами
```

Если проба внутри flex-элемента даёт странное значение `1ex`, сверьтесь с прямоугольником текста: `range.getClientRects()` отдаёт область от ascent до descent, базовая линия — `bottom − .295em`, x-height — `top + .475em`.

У мелкого кегля (12–14px) расхождение до 1px нормально: Chrome округляет метрики шрифта.
