# vasily.polovnyov.ru

Личный сайт и блог Василия Половнёва о разработке, тестировании и культуре работы. Jekyll, язык контента — русский.

## Сборка

Прод собирает GitHub Pages в классическом режиме (`build_type: legacy`) из ветки `master`: гем `github-pages`, то есть Jekyll 3.10 и Ruby Sass 3.7. Своего `Gemfile` в репозитории нет.

Локально:

```sh
jekyll build            # собрать в _site/
jekyll serve            # собрать и раздать на localhost:4000
```

Локальный Jekyll 4 собирает Sass через dart-sass, прод — через Ruby Sass. Если меняете стили заметно (новый синтаксис Sass, функции, CSS-функции вроде `min()`), проверьте сборку продовой связкой в отдельной папке, не добавляя `Gemfile` в репозиторий:

```sh
# Gemfile во временной папке: gem "github-pages", group: :jekyll_plugins
BUNDLE_GEMFILE=/tmp/pages/Gemfile bundle exec jekyll build --source . --destination /tmp/pages/site
```

Плагины `github-pages` превращают в страницы даже `.md` без front matter. Всё служебное (документацию, скрипты) добавляйте в `exclude` в `_config.yml`, иначе оно окажется на сайте.

## Устройство

- `_posts/` — посты, `YYYY-MM-DD-slug.md`, адрес `/posts/:title.html`.
- `_layouts/default.html` — страница поста: название, дата, текст, P. S., «Поделиться», «раньше-позже», плашка курса, рубрики «Популярное» и «Свежее».
- `index.html` — главная: карточка, 20 свежих постов целиком, архив остальных.
- `posts/index.html` — архив всех постов.
- `_includes/` — шапка, подвал, `<head>` с Метрикой, дата по-русски, таблица архива.
- `_sass/core/` — токены (`_tokens.scss`), сброс, шрифт, база и миксины (`_base.scss`).
- `_sass/modules/` — раскладка, пост, главная, подсветка кода.
- `js/errything.js` — самодельный типограф (неразрывные пробелы после коротких слов) и смена `<title>` при прокрутке ленты.
- `assets/fonts/` — Geist Mono, свои файлы, без CDN.

Не трогать:

- `/tests/` — лендинг курса в старом дизайне, музейный экспонат. У него свой замороженный `tests/legacy.css`, общие стили на него не влияют.
- `eye/`, `mba/`, `sandbox/`, `firepad.html` — старые самостоятельные страницы.

## Посты

Front matter:

```yaml
---
title: "Название"
layout: default
classes: favorite          # необязательно: звёздочка «любимое» в архиве
skip_tests_announce: true  # необязательно: не показывать плашку курса
---
```

Популярные посты перечислены в `popular_post_urls` в `_config.yml`.

Под каждым постом шаблон добавляет приписку про Телеграм и сам выбирает её номер: если в тексте есть абзац, начинающийся с «P. S.», будет «P. P. S.», если с «P. P. S.» — «P. P. P. S.». Писать P. S. в посте можно как обычно. Флаг `has_ps: true` включает «P. P. S.» вручную, если автоматика не распознала авторский P. S.

Посты — авторский текст. Не правьте их содержимое без явной просьбы, даже чтобы привести к новым правилам (например, entity в старых постах).

## Дизайн

Тёплая бумага, моноширинный Geist Mono для всего, синий акцент, пунктирные линии, плюсики по углам рамок. Цвета и отступы — только токены из `_sass/core/_tokens.scss`.

**Система отступов описана в [`docs/spacing.md`](docs/spacing.md). Прочитайте её перед любой правкой вёрстки.** Коротко:

- Отступы оптические: от базовой линии или края картинки до x-height. Текстовые блоки обрезаются миксином `trim-to-ink`.
- Шкала: просвет строки → межабзац (30px) → ¾ межстрочника → межстрочник (60px, два межабзаца) → два межстрочника (120px).
- Никаких произвольных `margin`/`padding` по вертикали. Если нужного значения нет в шкале, обсудите это, а не добавляйте новое число.
- Горизонтальные отступы (отступы списков, цитат, промежутки колонок) к ритму не относятся и задаются в `ch` или `--space-*`.

Проверяйте результат в браузере замерами, а не на глаз и не по коробкам в DevTools: как мерить, написано в `docs/spacing.md`. Проверяйте и мобильную ширину (390px): отступы те же, горизонтальной прокрутки быть не должно.

## Типографика

- **Никаких HTML entity** для типографских символов: пишите сам символ — неразрывный пробел U+00A0, кавычки «», тире «—», копирайт «©». Исключение — `&amp;` в атрибутах (URL с параметрами).
- **Неразрывные пробелы** после коротких слов (предлоги, союзы, частицы) ставит типограф, но только в `.post-contents` и `.post-title`. В шаблонах вне поста (карточка, плашка курса, подвал) ставьте U+00A0 вручную.
- **Склонение числительных** («1 пост», «2 поста», «5 постов») делайте правильно. Пример на Liquid — в `index.html`.
